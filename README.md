# WFM Trade Analyzer Web v0.2

Визуальный прототип без Supabase и без запросов к Warframe.market.

## Изменения v0.2

- Убраны дублирующие подписи режима и сортировки над таблицей
- Оставлен только счётчик найденных предметов
- Сортировка выполняется нажатием на заголовок любой колонки
- Повторное нажатие меняет направление сортировки
- Фильтры сокращены до названия, минимальной текущей цены и минимального потенциала
- Поиск по тексту работает только по названию предмета
